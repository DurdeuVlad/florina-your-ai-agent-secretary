Florina — UI Mockups

Static mockups of the shipped desktop app, matching the design guide in docs/UX_GUIDELINES.md and the five-item IA in docs/UX_INFORMATION_ARCHITECTURE.md (DEC-043). One shared stylesheet (mockup.css) holds the token mapping — change a token there and every screen follows. Nav items are links; Work's Tasks/Fleet/Ideas sub-tabs link across the three Work mockups, same as the real sub-tab bar.

Florina — home · launch view One journaled conversation with the Secretary. Messages + collapsed tool-activity rows, working indicator, docked composer with dictation mic (live partial text) and voice-mode toggle, and the live-activity drawer. Attention — needs-you inbox Needs you / Working / Done with live counts, the calm empty state, approval and digest cards with real action sets, and Prove-it affordances on completed work. Work · Tasks — drill-down Three columns: task list → SupervisorEvent timeline → event detail. Condensed ranges carry an expand marker; the fidelity notice shows on D/E-tier sessions. Work · Fleet — capacity Per-provider quota bars and reset times, parked tasks, recent routing decisions — the only screen where capacity lives. Work · Ideas — ledger Open ledgers with entry counts and previews, plus the compiled-Brief approval gate (DEC-033) surfaced as an inbox-style card. History — evidence Completed work and resolved decisions, plus journal search by text and date range. Settings — rules, memory, repos, desktop Routing rules and denies with provenance and scope chips, the memory/rules browse with kind+scope filters, repo roots and discovered repos, and desktop/voice preferences local to this device. Secretary — a lens inside Florina Her plan, in-flight research, pending memory writes, and context health. Not a nav item — the app reaches it as a lens on the Florina view. Push-to-Talk HUD — all states The header pill: idle / listening / processing / responding / offline. The only surface allowed to interrupt. Voice-mode overlay — all states (#182) Full-window immersive takeover for active two-way voice turns — listening / processing / responding. Distinct from the small PTT HUD.
