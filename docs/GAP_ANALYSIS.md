# Gap Analysis: Current Florina vs. Target Florina

This is not a frontend redesign checklist. Every row is a product-model gap
— something the codebase (per `AGENTS.md`, `DECISION_LEDGER.md`, and direct
inspection of `src/core/`) does not yet do that the target model in
`PRODUCT_DESIGN.md` + `docs/RULES_MEMORY_AND_SUPERVISION.md` +
`docs/PROVIDER_TOPOLOGY.md` + `docs/UX_INFORMATION_ARCHITECTURE.md`
requires. Each row is the basis for one issue in the
**Florina — Persistent AI Supervisor** milestone
([milestone #8](https://github.com/DurdeuVlad/agent-secretary/milestone/8)):
#191 (memory foundation), #192 (Execution Brief compiler), #193
(conversational rule learning), #194 (supervision ladder), #195 (catch-up),
#196 (Agent Profile), #197 (Observed tier), #198 (IA relabel), #199
(History), #200 (Settings memory audit), #201 (provenance trail), #202
(failover indicator), #203 (supervision cost metric).

  Settings audit surface.
