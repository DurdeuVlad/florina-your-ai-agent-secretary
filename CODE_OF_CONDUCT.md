# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, be constructive, assume good faith. Harassment,
personal attacks, and exclusionary behavior are not tolerated in any
project space — issues, PRs, discussions, or voice sessions.

Instances of unacceptable behavior may be reported by opening an issue or
contacting the maintainer directly via the repository's GitHub profile.
All reports will be reviewed and investigated promptly and fairly.
